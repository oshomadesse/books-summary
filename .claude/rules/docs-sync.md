# ドキュメント同期基準

`git push`する変更に応じて、次を確認する。

- **Node・Edge・Loop・Stateに触れる変更（最優先・必須）**: READMEの依存グラフ（mermaid）を同じpushで更新したか。依存グラフはHumanがグラフの詳細を監視できる唯一の場所であり、実態とズレた瞬間にHumanのValidation層が機能しなくなる。図が古いままのpushは差し戻し対象。
- 機能追加・設計変更: `docs/更新記録.md`に追記したか。更新記録は追記専用とし、過去の行を書き換えない。
- 設計判断そのものの変更: `docs/設計記録.md`も更新したか。
- README: フォルダ対応表、エラー出口一覧が実態と一致しているか。
- 生成物のみのpush: 何もしない。
- 初回push前: `docs/設計記録.md` の 0〜9 に空欄（記入）が残っていないか。
