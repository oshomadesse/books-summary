## 第7弾（2026-08-14）✅確認の図解URL解決を3段フォールバック化

- 2026-08-14 朝、クラウドpushが07:26:47、ローカルpullが07:20:00で6分半間に合わず、✅確認が「図解のURLが見つからんかった」を返した
- 過去12日のpushも07:14〜07:18で、pullまでのマージンは2〜6分しかなく構造的に再発する状態だった。pull時刻の変更では窓が狭まるだけなので、押された瞬間に最新を取れるよう `discord_books.py` の図解URL解決を「ローカル `state/latest.json` → vaultノート → GitHub raw の `latest.json`」の3段フォールバックにした
- GitHub raw のtimeoutは、Discordのinteraction callbackの3秒制限より内側となる2.5秒。取得した `date` が一致しないときは前日のURLを返さず空にする
- timeout は 2.0 秒。3秒制限は『インタラクション受信 → callback POST 完了』の全体予算なので、confirm_details 側で使い切ると Discord への ack が間に合わず『このインタラクションは失敗しました』に化ける。GitHub raw の実測は 0.15〜1.15 秒（8回・平均0.42）で、2.0 秒なら遅い方の1.7倍の余裕がある
- launchd plistとpullスクリプトは変更していない
- 解決順は『ローカル latest.json → GitHub raw → vaultノート』。vaultノートを最後にしたのは、ノートがiCloud退避されている日にhydrateが最大60秒ブロックし、Discordの3秒窓を食い潰してrawへ到達できなくなるため
- build_promptが案内するpullコマンドは絶対パス形で書く。settings.jsonのallowが絶対パス形の前方一致で、~形だと権限判定に一致しない
