## 第3弾（2026-07-24）06_Books 移設・Discord 化・LLM 関連リンク版

- リポを `11_Engineering/01_個人/📖 books-summary/` → `06_Books/` へ移設し graph-scaffold を接ぎ木（data→state 改名、旧システムを legacy へ、Books MOC 廃止）
- 通知を Discord `#📚06_books` へ移行（daily-notify.yml。Embed＋✅確認=図解リンク＋🔍詳細=モーダル→headless NEXUS 深掘り）。LINE は continue-on-error で並走、安定確認後に廃止予定
- GitHub Pages を「main/docs ブランチ配信」→「Actions 配信（infographics/ がルート）」に切替。docs 限定だった公開HTML 96本を infographics へ回収してから切替え、URL 完全互換を HTTP 200 で確認。docs/ は人間ドキュメント専用に解放

- 過去ノート一括リンクの道具 `src/tools/backfill_links.py`（scan/apply、適用前バックアップ、既リンク682件除外）を実装
- 実装は FABER（2 PART＋差し戻し1回: scan の既リンク除外漏れ）、git 作業は Sonnet、検証は NEXUS
