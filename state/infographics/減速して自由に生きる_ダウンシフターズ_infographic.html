🌾 減速して自由に生きる ダウンシフターズ

年収1000万円を手放した元エリート社員が実践する「自給・自信・自立・自由」の生き方

🎯 要約：問い×答え×根拠

❓ 問い

がむしゃらに稼ぎ、消費し続ける生き方の先に、本当の豊かさはあるのか？

💡 答え

稼ぐ額を自分で決めて「減速（ダウンシフト）」し、自給と人とのつながり（縁）を土台にすれば、収入は減っても自由な時間と心のゆとりを手に入れられる。

🔬 Why（なぜそうなのか）

大量生産・大量消費を前提にした資本主義システムの中では、「もっと稼ぎ、もっと消費する」ことが当たり前とされ、走り続ける限り時間もお金の心配も終わらない。著者・高坂勝は年収1000万円のエリート社員だったが、バブル崩壊後の心労で30歳のとき退職。1年間の旅と料理修行を経て、2004年に無借金で池袋にたった6坪のオーガニックバー「たまにはTSUKIでも眺めましょ」を開業した。年収を300万円ほどに減らしながらも、無理な集客をしない黒字経営と、千葉県匝瑳市での米・大豆の自給、人とのつながりを土台にすることで、時間的にも精神的にも自由な生き方を実現した。

🛠️ How（そのためには）

①支出を見直し「本当に必要な額」を自分で決める、②米や大豆など生活の基礎を自分の手で作る自給を始める、③カネの利益より人との縁（つながり）を資産として意識する、④会社や社会の「もっと稼ぐのが当然」という前提から一度降りてみる——という4つのステップで、無理なく段階的に実践していく。

  • 稼ぐ額をあえて減らし、それに応じて支出も減らす生き方
  • 「もっと稼ぐ」ことを前提にした人生設計から自ら降りるという選択
  • 収入を絞ることで、逆に時間という最大の資産を取り戻せる
理由：本書のタイトルであり全体を貫く中心概念。他のすべての概念はこのダウンシフトを実現するための具体的な手段だから。

💡 具体例

🍸 例1：エリート社員から6坪のバーオーナーへの転身

  • 背景：著者・高坂勝は大手小売チェーンに勤め、年収1000万円のエリート社員だった
  • 転機：バブル崩壊後の心労がたたり、30歳のときに退職。1年間の旅と金沢での料理修行を経る
  • 展開：2004年、無借金で池袋にたった6坪のオーガニックバー「たまにはTSUKIでも眺めましょ」を開業し、1人で8年間経営
  • 示唆：年収は1000万円から300万円程度まで減ったが、時間と心の自由を得た
理由（この例が示すこと）：本書の主張が理論ではなく、著者自身が実際に収入を大きく減らして得た実体験であることを裏づけるから。

🌾 例2：千葉県匝瑳市での米・大豆の自給とNPO法人SOSA PROJECT

  • 背景：2009年、バーを週休2日制にして、千葉県匝瑳市の田んぼで米と大豆の自給を開始
  • 展開：2012年には週休3日制に移行し、自給の範囲をさらに広げる
  • 発展：「自給」「電気」「家」「生業」の自立をテーマにNPO法人SOSA PROJECTを設立し、都市住民の移住・半農半Xの実践支援へと活動を広げた
  • 示唆：個人の自給実践が、他者を支援する社会的な仕組みへと発展した好例
理由（この例が示すこと）：「自給→自信→自立→自由」の連鎖が、個人の生活を超えて地域活動にまで広がっていく過程を具体的に示すから。

📉 例3：ヒマで繁盛しないのに黒字経営のバー運営

  • 背景：バーの1日の売上目標をあえて低く設定し、無理な集客や拡大をしない経営方針を貫く
  • 展開：従業員を雇わず、家賃の安い立地を選ぶことで固定費を抑え、少ない売上でも黒字を維持
  • 結果：週休2日から週休3日へと、段階的に休みを増やしながらも経営を続けられた
  • 示唆：売上の最大化ではなく、身の丈にあった規模を維持することが持続可能性につながる
理由（この例が示すこと）：「稼ぐ額は自分で決める」というダウンシフトの考え方が、具体的な経営数字として成立することを示すから。

⚡ 例4：SOSA PROJECTでの電気・住まいの自給活動

  • 背景：SOSA PROJECTは米づくりだけでなく、電気・住まいの自給にも活動範囲を広げている
  • 展開：太陽光など自然エネルギーによるオフグリッド発電、空き家の自力リノベーションなどを実践
  • 参加：年間約100人の都市住民が、味噌・醤油づくりや小屋の自力建築などのプログラムに参加
  • 示唆：自給の対象は食だけでなく、電気や住まいにまで広げられることを実例で示している
理由（この例が示すこと）：「自給」という概念が食料に限らず、暮らし全般の自立につながる幅広い実践であることを裏づけるから。

読後すぐに15〜30分で実行できる具体的な行動

📝 支出の棚卸しで「足るを知る」ラインを可視化する（15分）

目的：自分にとって本当に必要な支出額を把握し、収入を減らしても成立する生活水準の見当をつける

手順：

  • 📝 直近1ヶ月の支出項目を紙またはメモアプリに書き出す
  • 📝 「本当に必要な支出」と「惰性で続けている支出」に色分けする
  • 📝 惰性の支出を1つだけ選び、来月やめると決める

期待効果：「もっと稼がなければ」という漠然とした焦りが、具体的な数字に置き換わり、減速への現実的な一歩になる

🤝 「縁（ツナガリ）」に感謝を伝える（10分）

目的：カネではなく人とのつながりを資産として意識する練習をする

手順：

  • 📝 最近助けてもらった人・お世話になっている人を1人思い浮かべる
  • 📝 その人に短い感謝のメッセージを送る
  • 📝 送った後、自分の中に生まれた気持ちの変化に気づく

期待効果：お金では測れない人間関係という資産の存在に気づき、安心感の源が広がる

🐢 意図的に「減速」する時間を1つだけつくる（20〜30分）

目的：「システムから降りる」感覚を、日常の中で小さく体験する

手順：

  • 📝 今日の予定の中から「本当にそのペースが必要か」怪しいものを1つ選ぶ
  • 📝 その予定を意図的に早めに切り上げる、または1つ削る
  • 📝 生まれた時間で何もせず、景色や気分の変化をただ眺めてみる

期待効果：「減速すれば、景色が鮮明に見える」という帯文の感覚を、実際に短時間でも体感できる
