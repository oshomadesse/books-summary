🧠 3つのP（自責化・普遍化・永続化）

  • 心理学者マーティン・セリグマンが提唱した、逆境からの回復を妨げる3つの思考の罠
  • 自責化＝「全部自分のせいだ」、普遍化＝「人生の全部がダメになった」、永続化＝「これは永遠に続く」
  • どれも事実より誇張された思い込みであり、言語化して反証することで弱められる
理由：この3つを名付けて自覚できるだけで、思考の暴走に距離を置けるようになるから。

💪 レジリエンスは筋肉である

  • レジリエンスは生まれつきの資質ではなく、練習によって伸ばせる能力
  • 一度きりの出来事ではなく、生涯続く積み重ねのプロセスとして捉える
  • 失敗や後退があっても、鍛え直せば回復力は再び強くなる
理由：「自分はもう立ち直れない」という無力感そのものを外し、行動に意味を与えるため。

🌱 心的外傷後の成長

  • 深い苦しみを経た人の多くは、元に戻るだけでなく以前より強くなることがある
  • 新たな強さの自覚・人への感謝の深まり・人生の可能性の広がりとして現れる
  • 苦しみを美化するのではなく、回復の一側面として位置づける
理由：逆境＝ただの損失ではなく、成長の種にもなりうると知ることで希望を持てるから。

📝 「できたことリスト」で自己効力感を積む

  • アダム・グラントがサンドバーグに勧めた、毎晩「今日うまくできたこと」を3つ書く習慣
  • 幸せな出来事を数える「幸福日記」とは異なり、自分の行動・達成を数える
  • 小さな達成の自覚が、無力感の中でも「自分には力がある」という感覚を取り戻す
理由：感謝だけでは自信は戻らないが、達成の自覚は自己効力感に直結するから。

😔 サバイバーズ・ギルト

  • 急性の悲嘆が和らいでも、「自分だけ前に進んでいい罪悪感」は長く残る
  • 喜びを感じること自体に抵抗を覚えてしまう心理的ブレーキとして働く
  • 罪悪感の存在を認めた上で、喜びを取り戻すことは悲しみの否定ではないと理解する
理由：罪悪感を無視すると、回復の後半で足を止めてしまう人が多いから。

🐘 「部屋の中のゾウ」を追い出す

  • 気まずさから、周囲が苦しんでいる人の苦しみに触れずに済ませようとする態度
  • 触れないことは優しさではなく、本人を孤立させてしまう
  • まず話題にすること自体が、支援の最初の一歩になる
理由：沈黙が「見て見ぬふり」として伝わり、孤独をさらに深めてしまうから。

🤝 具体的な支援の原則

  • 「何か手伝うことある？」は本人に判断の負担を課し、結局使われにくい
  • 「明日の夕飯を届けるよ」のように、具体的な行動を申し出る方が実際に助けになる
  • これは個人間の支援にも、職場でのサポートにも共通する原則
理由：逆境の中にいる人は、新たな決断をする余力そのものが減っているから。

🏢 組織・職場のレジリエンス

  • 心理的に安全な職場は、個人が困難を率直に共有できる土台になる
  • 上司・同僚のオープンなコミュニケーションが回復の速度を左右する
  • 個人のレジリエンスだけでなく、それを支える関係性やチーム文化が重要
理由：レジリエンスは一人で鍛えるものではなく、周囲との関係性の中で育つものだから。

疑似章3

自分への思いやりと自己効力感

  • 自分を厳しく裁くのではなく、友人に接するように自分に接する「自己への思いやり」

疑似章5

子どものレジリエンスを育てる

  • 逆境にある家庭の子どもに対し、自信・自制心・発言力・コミュニティ意識を育む視点
  • 過保護に困難を取り除くのではなく、支えながら乗り越える経験を積ませる
理由：子どものレジリエンスは大人の支え方次第で大きく変わるから。
疑似章6

職場とコミュニティのレジリエンス

  • 個人の回復を、心理的安全性のある職場文化やコミュニティがどう支えられるか
  • オープンな対話と具体的な支援制度が、組織全体の回復力を高める
理由：個人のレジリエンスは職場という環境との相互作用で初めて機能するから。
疑似章7

喜びを取り戻す

  • サバイバーズ・ギルトと向き合い、喜びを感じることを自分に許す
  • 心的外傷後の成長として、新たな強さ・感謝・可能性を見出す
理由：回復のゴールは「悲しみを消すこと」ではなく「喜びと悲しみが共存できること」だから。

📝 今夜、できたことを3つ書く

目的：自己効力感を自覚し、無力感に歯止めをかける
  • 今日あった出来事の中から「自分がうまくできたこと」を3つ、紙かメモアプリに書き出す
  • 大小は問わない。小さな達成ほど見落としがちなので意識して拾う
期待効果：「自分には力がある」という感覚が少しずつ積み重なる

🗯️ 自分の中の「3つのP」を書き出して反証する

目的：思考の暴走（自責化・普遍化・永続化）を自覚し弱める
  • 今気になっている悩みについて「自分のせいだ／全部ダメだ／一生続く」と感じている部分を書き出す
  • それぞれに対し「本当にそう言える根拠は何か」を1行ずつ反証する
期待効果：思い込みと事実の区別がつき、気持ちの負荷が軽くなる

📞 誰かに「具体的な一言」を届ける

目的：「部屋の中のゾウ」を追い出し、相手を孤立させない支援を実践する

  • 「何か手伝うことある？」ではなく「〇〇するよ／〇〇していい？」と具体的なメッセージを送る
期待効果：相手が実際に受け取りやすい支援を届けられる
