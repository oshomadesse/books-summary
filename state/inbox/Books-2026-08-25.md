- [ ] 次の食事でタンパク質30g以上を意識する（肉・魚・卵・豆製品を組み合わせる）

### 🗣️ 要約
- 📣 核心的メッセージ
```
筋肉は単なる運動の道具ではなく、血糖値の調整・炎症の抑制・認知機能や気分の安定・老化への抵抗力までを担う「臓器」である。体脂肪や見た目ではなく骨格筋量こそが健康寿命を左右する最大の鍵であり、タンパク質を軸にした食事とレジスタンス運動を今日から始めることが、不老と好調に至る唯一の方法である。
```

- 🖊️ エグゼクティブ・サマリー
```
著者ガブリエル・ライオンは、骨格筋を代謝・炎症・認知・気分・加齢対策のハブとして再定義する「筋肉中心医療（Muscle-Centric Medicine）」を提唱する医師である。従来の健康診断や医療は「体脂肪と血糖値」を主役に据えてきたが、著者は臨床現場で「見た目はそれほど太っていないのに血糖コントロールが悪い」患者に繰り返し出会い、その共通点が骨格筋量の不足であることを発見した。

筋肉は運動のための組織であるだけでなく、体内最大の「血糖の貯蔵庫」であり、筋肉が収縮する際に分泌される「マイオカイン」という物質を通じて炎症のバランスを取る「制御センター」でもある。筋肉量が不足すると、血糖処理能力の低下・慢性炎症・気分の落ち込み・認知機能の低下が連鎖的に進行し、糖尿病や心血管疾患、さらには認知症のリスクまで高まるとされる。

本書が扱う「不老」は、肌や見た目の若返りではなく、年齢を重ねても動ける・回復できる・病気に対抗できる状態を維持することを指す。加齢とともに進行するサルコペニア（筋肉減少）こそが老化と要介護状態の本丸であり、見た目のアンチエイジングより先に筋肉量の維持に投資すべきだと著者は主張する。

具体的な実践法として、体重1kgあたり1.6〜2.2gのタンパク質を1日3食に分散して摂取すること（加齢による「同化抵抗性」への対策）、そして週2〜3回の高強度レジスタンス運動を行うことを柱に据える。本書にはレベル別の運動メニューと減量食レシピも収録されており、知識だけでなく今日から始められる具体的なプロトコルとして構成されている。

原題は『Forever Strong』で、全米でニューヨーク・タイムズ、ウォール・ストリート・ジャーナル、USAトゥデイの3大ベストセラーとなり、世界20カ国以上で刊行されている。
```
